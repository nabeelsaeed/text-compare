# Text Compare

A lightweight, browser-based tool for comparing two versions of text side by side.

## Features

- **Word, Line, or Character** level comparison
- **Inline or Side-by-side** view
- Similarity percentage and change statistics
- Ignore case and ignore whitespace options
- Dark mode support
- No data leaves your browser — everything is processed locally

## Usage

1. Paste the original text in the left box
2. Paste the changed version in the right box
3. Differences appear instantly below

Removed text is struck through in red. Added text is highlighted in green.

## Run Locally

Just open `index.html` in any modern browser — no build step or server required.

## Tech

Pure HTML, CSS, and JavaScript. No dependencies or frameworks.
